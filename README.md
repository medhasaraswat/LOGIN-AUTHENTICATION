# LOGIN-AUTHENTICATION
🔐 Login Authentication System

📌 Project Overview
The Login Authentication System is a simple web-based application developed as part of the Oasis Infobyte Web Development Internship (OIBSIP) - Level 2 Task 4. This project allows users to register, log in, access a secure dashboard, and log out securely.
The application uses HTML, CSS, and JavaScript with Local Storage for storing user credentials and managing authentication.

🚀 Features
User Registration
User Login Authentication
Password Confirmation Validation
Secure Dashboard Access
Logout Functionality
Responsive User Interface
Local Storage Data Management
Input Validation and Error Handling

🛠️ Technologies Used
HTML5
CSS3
JavaScript (ES6)
Local Storage API
